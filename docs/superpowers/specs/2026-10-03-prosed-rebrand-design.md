# prosed: rebrand design

Date: 2026-10-03

## Why

This repo started as a fork of [nucleartux/ai-grammar](https://github.com/nucleartux/ai-grammar). It now has in-field underlines, rewrites, a personal dictionary, remembered dismissals, a benchmark and a desktop app that checks text in every app on the machine. The upstream name, "AI Grammar Checker", describes the upstream extension and says nothing about this one. GitHub no longer lists the repo as a fork (detached on 2026-10-03).

The project stays an open source tool shared through GitHub releases. There is no Chrome Web Store listing. A site may come later to present the features.

## Identity

**Name.** `prosed`, always lowercase, also at the start of a sentence, like `git` or `npm`. It reads as "sed for prose" and as the past tense of "prose". `prosed.dev`, `prosed.app` and `prosed.sh` had no DNS records on 2026-10-03, and no GitHub project of note uses the name.

**Taglines.** Two lines that always go together:

- Under the logo: `sed for your prose.`
- As the description (README intro, manifest, GitHub repo): `A grammar checker that runs on your machine.`

The joke is for developers. The plain line tells everyone else what the tool does.

**Icon.** Variant B5 from the brainstorm, in the paper palette. A rounded square in paper color with a thin ink outline. One thick ink wave crosses it, cut by a vertical text cursor. The wave is the spell checker's squiggle, the cursor is where you type.

Three SVG sources live in `assets/brand/`:

| File | Use |
|---|---|
| `prosed.svg` | The full icon, 48 px and up: extension 48/128, desktop app bundle |
| `prosed-small.svg` | Thicker strokes, no outline, for 16 and 32 px. The full drawing blurs at those sizes. |
| `prosed-tray.svg` | Wave and cursor only, black on transparent, for the macOS menu bar |

Every raster icon is generated from these files. Nobody edits a PNG by hand.

**Color.** The brand has no hue of its own. Color only carries meaning in the product, and the brand stays ink on paper.

| Role | Value |
|---|---|
| Paper | `#ece7dc` |
| Ink | `#15181d` |
| Mistake | `oklch(66% 0.19 29)`, unchanged |
| Fix | `oklch(72% 0.15 152)`, unchanged |
| Rewrite | `oklch(70% 0.15 290)`, unchanged |

**Type.** IBM Plex Mono for the wordmark, the taglines and anything that reads like a command. IBM Plex Sans for running text. Both are under the SIL Open Font License.

The fonts ship inside the extension and the desktop app as `woff2` files. Neither loads anything from Google Fonts. A request to a font CDN each time the settings open would break `PRIVACY.md`, which says no third-party API is used.

**Unchanged on purpose.** The underlines, cards and badge drawn inside web pages and other apps keep the system font and their automatic light or dark look. They have to blend into the page the user writes in.

## Where it applies

### Chrome extension

- `package.json`: `name` and `displayName` become `prosed`, `description` becomes `A grammar checker that runs on your machine.`, version `0.11.0`.
- `src/manifest.ts`: the action title becomes `prosed settings`. The icon paths follow whatever file names the generator writes.
- `public/img/`: 16 and 32 from `prosed-small.svg`, 48 and 128 from `prosed.svg`.
- Options page (`src/options/`): the header shows the icon, `prosed` in Plex Mono and `sed for your prose.` under it. The page uses Plex Sans. In light mode it is ink on paper, in dark mode paper on ink. It keeps following the system theme as it does today.
- `localStorage["ai-grammar:debug"]` becomes `localStorage["prosed:debug"]` (`src/contentScript/index.ts:341-343`), and the test in `src/contentScript/text.test.ts:31` follows.

### Desktop app

- `desktop/src-tauri/tauri.conf.json`: `productName` becomes `prosed`, `identifier` becomes `com.florianlauer.prosed`.
- `desktop/src-tauri/Cargo.toml`: the crate becomes `prosed`, and the lib and binary names follow. `Cargo.lock` is regenerated.
- `desktop/src-tauri/src/lib.rs`: the window title, the tray tooltip and the "Quit prosed" menu item.
- `desktop/index.html`: title and header, same header as the options page.
- `desktop/src-tauri/icons/`: regenerated by `cargo tauri icon` from `prosed.svg`.
- The menu bar icon stops reusing the app icon (`lib.rs:683`). It loads the PNG generated from `prosed-tray.svg` and is set as a template image on macOS (`icon_as_template(true)`). macOS then draws it black or white to match the menu bar, like native icons. Windows keeps the color app icon in the tray.
- The settings window already imports the options page script and its CSS (`desktop/src/settings.ts:3`), so it picks up the new look with no extra work.

### Repo and docs

- `README.md` opens with the logo, the two taglines and the current feature list. "This is a fork of…" moves out of the intro into "Credits and license", which keeps Igor Adrov's credit, the sponsor link and the MIT license.
- `AGENT_INSTALL.md`, `desktop/README.md`, `desktop/LINUX.md`: the name and the paths change (`prosed.app`, `prosed` zip names, repo URLs).
- `PRIVACY.md` is the upstream author's blanket policy, in his voice ("extensions I create"). It gets rewritten as prosed's own policy, covering the extension and the desktop app: the text goes to the local Ollama server or Chrome's on-device model and nowhere else, nothing is collected, settings stay in browser storage or the app's config file.
- `CHANGELOG.md`: a 0.11.0 entry. It says the extension has a new name and tells users to unzip the new release over the folder they already load it from, even if that folder is called `ai-grammar`: Chrome derives the ID of an unpacked extension from its folder and settings live under that ID, so a new folder means empty settings. It also gives the one-time command for desktop users on macOS (and the Windows equivalent):

  ```
  mv ~/Library/Application\ Support/com.florianlauer.ai-grammar ~/Library/Application\ Support/com.florianlauer.prosed
  ```

  macOS asks for the Accessibility permission again once, because it ties the permission to the bundle identifier.
- `assets/settings.png` is retaken to show the new header. The other screenshots show the in-page UI, which does not change.
- The GitHub repo `florianlauer/ai-grammar` becomes `florianlauer/prosed`, with description `A grammar checker that runs on your machine.` GitHub redirects the old URLs. This is the last step, after the rebrand PR is approved.

### Left alone

- The internal CSS prefix `aig-` (`.aig-root` and the rest). Users never see it, and renaming it would add hundreds of lines to the diff for nothing.
- Old CHANGELOG entries keep the old name. They describe releases that shipped under it.

## Migration

No migration code. The desktop app is at an early stage and its users are few, so the `mv` command in the CHANGELOG is enough. The extension cannot be migrated from code anyway: a new install from a new folder is a new extension ID with empty storage.

## Out of scope

- The `prosed.dev` site. Buying the domain is Florian's call. This work leaves what the site will need in `assets/brand/`: the SVGs, the colors and the font choice.
- Any change to how the in-page overlays look.

## Verification

- `npm test` and `npm run build` pass.
- `cargo check` passes in `desktop/src-tauri`.
- `grep -rniE 'ai.grammar|aigrammar'` finds nothing outside old CHANGELOG entries and the credits section.
- A headless Chromium screenshot of the built options page, light and dark.
- On the Mac, by hand: the app builds as `prosed.app`, the menu bar icon is monochrome and switches with the menu bar theme, the Accessibility prompt names `prosed`, and the `mv` command brings back the old settings.
